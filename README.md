# Nonholonomic Source Seeking With a Rotating Sensor

Supplementary video for **Nonholonomic Source Seeking With a Rotating Sensor: Safe Scanning and Unbiased Convergence to the Constrained Optimizer**.

[Watch the Gazebo demonstration](https://xuebin-li-hit.github.io/nonholonomic-source-seeking/)

[Download the video](gazebo_demo.mp4)

The video shows a separately recorded closed-loop Gazebo run with the same initial conditions as S2 in the manuscript. The vehicle passes through a doorway while seeking an indoor source using lidar measurements.

- Simulator: Gazebo Harmonic with ROS 2 Jazzy
- Video: 42 seconds, 1920 x 1080, 30 fps
- The playback speed and simulation time are displayed in the video.
